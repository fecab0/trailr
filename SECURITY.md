# Security policy

If you find a security problem in Trailr (for example, a script that could leak credentials or run unexpected commands), please **do not open a public issue**.

Report it privately instead: go to the [Security tab](https://github.com/fecab0/trailr/security) and click **Report a vulnerability**. Only the maintainers can see the report.

We will reply as soon as we can, and credit you once it is fixed if you wish.
